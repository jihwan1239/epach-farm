# 복숭아 농장

픽셀 그래픽으로 만든 방치형 복숭아 농장 게임이에요. 가끔 들어와서 나무를 톡톡 눌러 돌봐 주면 됩니다.

## 노는 법
- 나무를 누르면 그때 필요한 일을 알아서 해요. 물방울 말풍선이 뜨면 물 주기, 가위가 뜨면 가지치기, 복숭아가 뜨면 수확이에요.
- 할 일이 없을 때 누르면 쓰담쓰담 해서 조금 더 빨리 자라요.
- 흰 바탕에 노란 얼룩 고양이가 나무 옆에서 낮잠을 자면 그 나무는 안 자라고 물도 빨리 말라요. 세 번 눌러서 쫓아내면 코인을 줘요. 한 번 누를 때마다 도망 다녀요.
- 새는 익은 복숭아를 쪼아 먹어요. 눌러서 쫓아내세요.
- 앱을 꺼 둬도 시간은 흘러요. 물이 다 마르면 성장이 멈춥니다.
- 하늘은 실제 시간에 맞춰 낮, 노을, 밤으로 바뀌어요.

## GitHub Pages로 올리기
1. GitHub에서 새 저장소를 만들어요 (예: `peach-farm`).
2. 이 폴더의 파일을 전부 올려요: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`
3. 저장소 Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 두고 저장해요.
4. 1~2분 뒤 `https://<아이디>.github.io/peach-farm/` 에서 열려요.
5. 휴대폰에서 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.

## 손보기 좋은 곳 (index.html 위쪽 설정 부분)
- `STAGE_MIN` 단계별 성장 시간(분)
- `WATER_MIN` 물이 다 마르는 시간(분)
- `PRUNE_MIN` 가지가 무성해지는 시간(분)
- `SLOT_COST`, `UPGRADES` 가격
- `PEACH_PRICE`, `GOLD_PRICE` 판매가

저장은 브라우저 localStorage에 돼요. 다른 기기와는 공유되지 않아요.
